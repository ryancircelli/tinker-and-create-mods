## Swapped (10)

| Replaced | With | Why |
| --- | --- | --- |
| Hephaestus | Tinkers Construct | Fabric port replaced by the official mod on Forge/NeoForge (then lost entirely on 1.21 — see TODO.md) |
| Trinkets | Curios API | Fabric accessory API has no Forge equivalent; Curios is the standard |
| Farmer's Delight Refabricated | Farmer's Delight | unofficial Fabric port replaced by the original |
| Sophisticated Backpacks/Storage (Fabric ports) | official Sophisticated mods | unofficial ports replaced by upstream |
| Charm Forked | Quark | Fabric kitchen-sink replaced by the Forge equivalent |
| Charmonium | AmbientSounds | Fabric-only ambience replaced |
| Forgotten Graves | Corail Tombstone → Corpse | two hops: loader swap, then simplified again on 1.21 |
| Embeddium | Sodium + Iris | Embeddium conflicts with Veil and Iris on 1.21.1; Sodium is native there |
| Dynamic Lights | LambDynamicLights | Swapped for LambDynamicLights (51M downloads, in 6/34 reference packs, native NeoForge 1.21.1). Same feature, far better maintained — this was a 1.20.1-era mapping choice. |
| Corail Tombstone | Corpse | Swapped for Corpse (8/34 reference packs). Tombstone is a large magic-flavoured death system; Corpse just leaves a body holding your items, which fits a Create pack better. |

## Rejected (42)

- **Amendments** `amendments`
  Hard-requires Moonlight Lib; dropped with it by the ban cascade. See the moonlight ban reason.
- **Better Combat** `better-combat`
  Only Combat-category mod in a pack with no dungeon/mob/adventure content, and its attack handling overlaps Hephaestus weapon mechanics.
- **Carrier** `carrier`
  Duplicates Carry On, which is already in the pack.
- **Chipped** `chipped`
  Overlaps Rechiseled (both add block variants). Kept Rechiseled because the pack also ships Rechiseled: Create, which bridges it to Create's palettes — Chipped has more raw downloads but no Create integration.
- **Chunk Loaders** `chunk-loaders`
  Redundant with Create: Power Loader, which does the same job Create-natively (loaders driven by rotational power) and has higher adoption. Same reasoning as keeping Rechiseled over Chipped: in a Create pack, the mod that plugs into Create's progression wins. Chunky stays — it pre-generates terrain, which is a different job from runtime chunk loading.
- **Clockwork / Create: Interactive** `create-clockwork`
  Both require Valkyrien Skies. VS2 is a large physics framework with a big performance and stability surface; not worth the risk in this pack. Revisit if you want buildable vehicles badly enough to test it in isolation.
- **continuity** `continuity`
  Fabric-only; runs via Sinytra Connector on NeoForge and crashes on EVERY item render. EmissiveItemQuadTransform.transform throws NPE (SpriteFinder.find null) inside Sodium's FRAPI item path — caught rendering Create's menu button icon. Redundant anyway: Fusion provides connected textures natively on NeoForge with 39 builds. Found by jointest.js screenshot, not by any log check.
- **Create Contraption Terminals** `create-contraption-terminals`
  Requires toms_storage. It is a bridge mod for Tom's Simple Storage, not standalone; the pack already has Sophisticated Storage and Storage Drawers.
- **Create Encased** `createencased`
  No Fabric 1.20.1 build on Modrinth (SuperMartijn642 stopped at Forge). Nearest Fabric equivalent is 'Create: Transmission!' — different mod, not a drop-in.
- **Create Stuff 'N Additions** `create-stuff-n-additions`
  No Modrinth project with a Fabric 1.20.1 build.
- **Create Track Map** `create-track-map`
  Only 1.20.1 build is 2023-10-19, pre-Create-6.
- **Create Utilities** `create-utilities`
  Re-checked on request: still has no NeoForge 1.21.1 build. Its newest builds stop at 1.20.1.
- **create-aeronautics** `create-aeronautics`
  Flying contraptions — not wanted.
- **create-big-cannons** `create-big-cannons`
  Cannons/artillery — not wanted.
- **create-propulsion-simulated** `create-propulsion-simulated`
  Propellers/thrusters for contraptions — same flying-contraption family as Aeronautics.
- **create-shuffle-filter-fabric** `create-shuffle-filter-fabric`
  Mixin MixinFilterItem @Injects into FilterItem.getFilterItems with a Porting Lib ItemStackHandler return type. That signature no longer exists in Create 6.0.8.1, so the mixin fails to apply, Create's AllItems/AllBlocks clinit dies, and every Create addon cascades with NoClassDefFoundError. Declares no create dependency, so no static check catches it — confirmed only by launching.
- **create-teleporters** `create-teleporters`
  Teleportation — not wanted, and it undercuts the rail investment the same way Waystones did.
- **create-tfmg** `create-tfmg`
  Heavy industry addon with an electricity layer — excluded with the other electricity mods.
- **create-ultimine** `create-ultimine`
  Bridge mod requiring FTB Ultimine (ftbultimine >=2101.1.14), which the pack does not ship — VeinMiner already covers vein mining. The FTB dependency is not declared on Modrinth, so only a boot catches it.
- **Create: Addon Compatibility** `createaddoncompatibility`
  Ships 8 data/tfmg/ recipes that fail to parse because TFMG is excluded as an electricity mod (8 RecipeManager errors every startup). Its only other content is 3 Copycats item tags that nothing in this pack consumes. Its purpose is bridging addons we deliberately do not have, so it is net negative.
- **Create: Big Contraptions** `big-contraptions`
  Only 1.20.1 build is 1.0 (2024-02), pre-Create-6, and client-only — so the server smoketest cannot validate it. Not shipped unvalidated.
- **Create: Design n' Decor** `create-design-n-decor`
  fabric.mod.json pins create EXACTLY 0.5.1-f-build.1417. Unsatisfiable against Create 6.0.8.1 — the loader hard-fails at startup. Newest 1.20.1 build is 0.4.0b (2024-08-04); no Create 6 build exists.
- **Create: Dragons Plus** `create-dragons-plus`
  Only alpha builds exist for Fabric 1.20.1 (1.11.4-p.1/p.2/p.3, all within three days). Its ContraptionMixin argument modifier removeBlocksFromWorld$preserveContainedFluid scanned 0 targets against Create 6.0.8.1 and hard-failed at startup, despite declaring create >=6.0.8.1 <6.1.0.
- **Create: Extra Gauges** `create-extra-gauges`
  Not on Modrinth at all.
- **Create: Oxidized** `create_oxidized`
  Only 1.20.1 build is 0.1.1 (2024-01). Links against com.simibubi.create.foundation.utility.{Components,Lang}, which Create 6 moved into Catnip — NoClassDefFoundError at registration.
- **Create: Radars** `create-radars`
  Hard-requires createbigcannons >=5.11.2, which was dropped on request. Radars is a targeting addon for the cannons, so it goes with them.
- **Create: Recycling** `create-recycling`
  Pins create to exactly 0.5.1-j-build.1631+mc1.20.1 — the same unsatisfiable-pin signature as Design n' Decor and Create: Storage.
- **Create: Sophisticated Backpacks** `create-sophisticated-backpacks`
  No NeoForge 1.21.1 build — the Create/Sophisticated Backpacks bridge stops earlier.
- **Create: Stam1o Tweaks** `create-stam1o-tweaks`
  From Just Create SMP 2. Declares no create dependency and its only 1.20.1 build is 2024-10-03 — a year before Create 6. Same profile as the addons that caused the 1.0.3 startup crash.
- **Create: Storage** `fxnt-create-storage`
  fabric.mod.json pins create to exactly 0.5.1-f-build.1417 — the same unsatisfiable pin that made Design n' Decor hard-fail at startup.
- **createnuclear** `createnuclear`
  Nuclear power generation (energy/electricity) — excluded.
- **createschematicchecker** `createschematicchecker`
  Redirector interceptSlot1 targets SchematicTableBlockEntity$SchematicTableInventory and fails its injection check against Create 6.0.8.1, aborting startup. Declares create:"*" and was published 2026-07-11, so nothing static flags it — caught only by smoketest.
- **Easy Villagers** `easy-villagers`
  No Fabric 1.20.1 build published.
- **Gravestone Mod** `gravestone`
  Slug does not exist; and Forgotten Graves already fills this role. Two grave mods conflict on the death-drop event.
- **hypertube** `hypertube`
  Hypertube transport — not wanted.
- **item-borders** `item-borders`
  Mixin conflict: duplicate event invoker crash with Iceberg/Prism.
- **Just Enough Resources** `just-enough-resources-jer`
  Hard-requires JEI, which would ship a second recipe viewer alongside EMI. EMI Ores + EMI Loot cover the same ground.
- **Ledger** `ledger`
  Breaks Vein Mining: with Ledger present, SpectreLib's preLaunch stage fails with ServiceConfigurationError on veinmining's FabricPlatform (no usable no-arg constructor), aborting startup. Bisected in the smoketest workspace — the other four additions boot fine together. Downgrading Vein Mining to 1.4.1 did not help. Not worth it for a private server anyway; Ledger is griefing forensics.
- **power-grid** `power-grid`
  Electricity distribution for Create — excluded.
- **supplementaries** `supplementaries`
  Empirically re-confirmed by tools/jointest.js on 2026-08-07. Adding the Moonlight chain makes the client fail to decode Hephaestus's station-layout packet during login: DecoderException -> IllegalStateException 'Attempted to load a modifier before dynamic modifiers are loaded' (LazyModifier.get -> StationSlotLayout.read), and the client disconnects. 1.1.3 (no Moonlight) joins cleanly; 1.1.4 (with it) does not — same client, same server, same everything else. The 1.0.2 'moonlight:add_item loot modifier' explanation was wrong (that code no longer exists upstream), but the CONFLICT IS REAL: the Moonlight chain adds dynamic registry content that changes load ordering so Tinkers modifiers resolve too early.
- **Tree Harvester** `tree-harvester`
  Vein Mining already covers tree felling; overlapping intent.
- **Waystones** `waystones`
  Design conflict, not a technical one. The pack invests in five rail mods (Steam 'n' Rails, Railways Navigator, Train Utilities, Train Lights, Threaded Trains); player teleportation makes a rail network decorative.
